运行状态

frps 最近输出

frp 监听端口

frpc 连接服务端使用的端口（bindPort）；首次启动默认随机生成，可在此手动固定

修改后 frps 自动重启；客户端将在下次心跳后自动切换到新端口

由环境变量 FRP_BIND_PORT 固定时不可修改

从节点监听端口

远程修改各从节点的 frps 监听端口；命令经同步通道下发，从节点执行后自动重启 frps 并放行防火墙

从节点离线时无法下发；修改结果将在该节点下一次同步时刷新显示

HTTP/HTTPS 隧道端口

HTTP 隧道按 Host 头路由、HTTPS 隧道按 SNI 透传；客户端自定义域名（customDomains）走这两个端口

默认关闭（0）；填写 80 等端口后开启 HTTP 隧道
默认关闭（0）；填写 443 等端口后开启 HTTPS 隧道

由环境变量 FRP_VHOST_HTTP_PORT / FRP_VHOST_HTTPS_PORT 固定时不可修改
